# Mithaq — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Government entity dataset steward

- As a steward, I want to publish my dataset with its access terms and receiver obligations once, so that I stop renegotiating the same conditions with every applicant.
- As a steward, I want to see what a requester will be obliged to do with my data before I approve, so that approving does not feel like relinquishing control of a strategic asset.
- As a steward, I want a reciprocity term that gives contributors better access than consumers, so that sharing improves my own position rather than only someone else's.
- As a steward, I want to refuse with a recorded reason inside the service period, so that a refusal is a defensible decision rather than an unanswered request.

### Research data officer

- As a research data officer, I want to request a genomic cohort and be told immediately if its size breaches the re-identification threshold for our population, so that I can ask for an aggregate or synthetic release instead of losing months to a refusal.
- As a research data officer, I want a corpus described consistently enough that I can reuse it for a second application, so that curation done once serves more than one project.
- As a research data officer, I want my compact to survive a change of steward at the holding entity, so that a personnel change does not silently end my access mid-study.

### Ethics tier reviewer

- As a tier reviewer, I want to assign an explainability tier to the decision class rather than to the dataset, so that the same clinical data can carry a light duty for research and a heavy duty for allocating a transplant.
- As a tier reviewer, I want the tier criteria to be locally editable and versioned, so that the framework can hold both Qatari norms and international guidance without one silently overwriting the other.
- As a tier reviewer, I want an application in the highest tier blocked from production use until it can produce a plain-language account of an individual decision, so that the organ-allocation failure mode is prevented before deployment rather than discovered after.

### Sandbox operator

- As a sandbox operator, I want to authorise an event-window pilot in days with a hard end date and a bounded participant population, so that a non-repeatable data-generation opportunity is not lost to review time.
- As a sandbox operator, I want expiry to force deletion or explicit re-permissioning, so that a pilot cannot quietly become a permanent unauthorised system.
- As a sandbox operator, I want the non-cost justification for a pilot recorded at authorisation, so that a pilot approved for quality or strategic-control reasons is not later cancelled on a unit-cost comparison.

### National AI committee secretariat

- As the secretariat, I want to elevate a specific sharing guideline into a mandatory policy for government entities and see which compacts change mode as a result, so that the escalation has a visible, auditable effect.
- As the secretariat, I want a standing register report of shares, obligations, tiers, breaches and derived applications, so that I can brief the Prime Minister's office and support a multilateral proposal with evidence.
- As the secretariat, I want obligation breaches to suspend a receiver's active compacts across every holding entity at once, so that a breach against one ministry is not invisible to the next.
